# Day Ahead — a Home Screens plugin

The weather when you leave, when you come home and hour by hour through the day — with heads-ups for umbrella, frost on the windshield, slippery roads and wind.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-day-ahead/releases/latest/download/day-ahead.tgz
```

Build: `npm install && npm run build`
